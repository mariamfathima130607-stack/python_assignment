# Python Assignment Repository

This repository contains a collection of Python scripts demonstrating fundamental programming concepts including mathematical operations, control flow, loops, data structures (lists and strings), and basic algorithms.

---

## 📚 Table of Contents & Script Summaries

| Script Name | Description |
| :--- | :--- |
| `anagram.py` | Checks whether two strings are anagrams of each other. |
| `armstrong_number.py` | Verifies if a given number is an Armstrong number (n-digit number equal to the sum of the $n$-th powers of its digits). |
| `character_count.py` | Counts occurrences of characters within a string. |
| `check_negative_positive_zero.py` | Evaluates if a input number is positive, negative, or zero. |
| `composite.py` | Determines if a number is a composite number (positive integer with more than two factors). |
| `count.py` | Demonstrates counting occurrences or specific criteria in sequence data. |
| `digit_count.py` | Counts total number of digits present in a given integer. |
| `even_odd.py` | Checks whether an integer is even or odd using modular arithmetic. |
| `factorial.py` | Computes the factorial of a given non-negative integer. |
| `fibonacci.py` | Generates the Fibonacci sequence up to a specified number of terms. |
| `fizzbuzz.py` | Implements the classic FizzBuzz game logic (multiples of 3 and 5). |
| `gcd.py` | Computes the Greatest Common Divisor (GCD) of two integers. |
| `grade_calculator.py` | Assigns letter grades based on total score/percentage input. |
| `largest_number.py` | Finds the maximum value among user-provided numbers. |
| `lcm.py` | Calculates the Least Common Multiple (LCM) of two numbers. |
| `leap_year.py` | Checks if a given calendar year is a leap year based on leap year rules. |
| `ma_min_list.py` | Finds the maximum and minimum elements in a list of numbers. |
| `multipication_table.py` | Displays the multiplication table for any given integer. |
| `palidrome.py` | Tests if a string or number reads the same forwards and backwards. |
| `perfect.py` | Checks if a number is a Perfect Number (equal to the sum of its proper divisors). |
| `prime.py` | Checks whether a given integer is a prime number. |
| `reversing_number.py` | Reverses the digits of an integer. |
| `second_largest_list.py` | Identifies the second largest element in a numeric list. |
| `simple_interest.py` | Computes Simple Interest ($SI = \frac{P \times R \times T}{100}$). |
| `star.py` | Generates visual star patterns using nested loop iterations. |
| `sum_avg_list.py` | Calculates the total sum and average value of numbers in a list. |
| `sum_of_digits.py` | Calculates the sum of individual digits of a number. |
| `sum_of_natural.py` | Computes the sum of the first $N$ natural numbers. |
| `swapp.py` | Swaps values of two variables with/without temporary variable. |
| `vowels.py` | Identifies and counts vowels contained in a string. |

---

## 🛠️ Usage

To run any script locally, execute it using Python 3 from your command line:

```bash
python <script_name>.py
```

For example:
```bash
python fizzbuzz.py
```
